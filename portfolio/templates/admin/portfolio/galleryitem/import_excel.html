Spreadsheet Formatting Rules

  • Title: The name of the project (e.g. Kanyakumari Villa). Optional.
  • Category: Must be one of the seven valid design categories: Elevation Design, Residential Houses, Residential Villas, Interior Design, Landscape Design, Commercial Buildings, or Renovation & Remodeling (case-insensitive, spelling matters).
  • Image URL: A fully qualified HTTP or HTTPS link to the image (e.g. https://images.unsplash.com/...). The backend will automatically fetch this file and save it in the database.
  • Description: Brief text or details about the project. Optional.
  • Order: An integer (e.g., 1, 2, 3) to set display order. Defaults to 0.
